<h1>A WoW style chat overlay for Twitch</h1>

<p>
Currently you can change colour/formatting for:
  <li>Broadcaster</li>
  <li>Moderator</li>
  <li>Subscriber</li>
  <li>Highlighted Messages</li>
  <li>Regular Chatters</li>
</br>
  The chat box also respondes to:
  <li>A user subscribing</li>
  <li>A user resubscribing</li>
  <li>A user gifting a sub</li>
  <li>A user donating bits</li>
  <li>A user raiding</li>
</br>
  To make it connect to your channel, change the line in the header "let streamer = "YOUR STREAM NAME HERE"; "</br> 
  You can change how the different chatter roles are formatting by changing the corresponding variables in the header </br>
  To add it to your OBS, add a browser source and paste in the file path that leads to wherever you have this saved. Eg: E:\Docs\Documents\TwitchChatBox\Chatbox.html</br> 
  
  Size should be 800 x 360
</p>
